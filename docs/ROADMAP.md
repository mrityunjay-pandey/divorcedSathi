# Roadmap & Working Agreement

## How we work

For every module, before writing code I will:
1. Explain the module's scope and boundaries.
2. List files to be created/modified.
3. Describe DB/API changes.
4. Note dependencies on prior modules.

Then implement, and afterward provide:
- Setup instructions
- Testing instructions
- A manual QA checklist
- Known limitations
- The suggested next module

No module is skipped silently if its tests fail. No previously completed module is rewritten without being asked.
